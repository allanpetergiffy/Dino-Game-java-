# Java Dino Game 🦖🌵

A lightweight, arcade-style clone of the classic **Chrome Dinosaur Game** built entirely in **Java** using Java Swing. Test your reflexes by jumping over incoming cacti obstacles as the game gradually speeds up!

---

## Features

- **Smooth Physics**: Built-in gravity and jump acceleration mechanics.
- **Dynamic Obstacles**: Randomized cacti movement with progressive difficulty scaling (speed increases as your score goes up).
- **Score Tracking**: Real-time score counter displayed directly on the screen.
- **Game Over & Restart Loop**: Clean collision detection with an instant restart option (`R` key).
